# voxtalk

Text-to-speech in the voice of Half-Life's VOX facility announcer, generated by
AT&T FlexTalk (the 1997 speech engine) running directly on modern Windows.

FlexTalk was only ever usable on Windows XP and earlier, and only through a full
SAPI installation. voxtalk loads the original engine in-process with no install,
no admin rights and no registry changes, then applies the processing measured
from the game's own `sound/vox` files: pitch, speed, echo, filtering and 8-bit
quantisation.

- Single portable `voxtalk.exe` (about 4.4 MB) with the engine and voice data built in
- Window for interactive use plus a command line for scripting
- WAV or MP3, at 11025 Hz (as in the game) or 44100 Hz
- "Word by word" mode that speaks each word separately, like the game's sentence system
- Export one file per word, ready to drop into a `sound/vox`-style folder

## Download

Grab `voxtalk.exe` from the [Releases](../../releases) page and run it. Requires
Windows 8 or later (32- or 64-bit). On first start the engine is unpacked to
`%LOCALAPPDATA%\voxtalk`.

## Using the window

Type text, press **Speak**. **Save as...** writes a single file, **Save words...**
writes one file per word into a folder. Every slider starts at the VOX
calibration; **Reset to VOX defaults** puts them back.

| Control | What it does |
|---|---|
| Style | *Word by word* speaks every word on its own (in-game style); *Whole sentence* uses FlexTalk's natural phrasing |
| Pitch, Expression, Speaking rate, Head size | FlexTalk's own voice parameters (0-100) |
| Playback speed | Slows the voice like a slowed tape, lowering pitch and formants together |
| Echo amount / delay | The feedback echo heard in VOX (100 % = as measured) |
| Low cut | High-pass filter |
| 8-bit | Quantises to 8 bits like the game files; at 11025 Hz WAV the file is written as 8-bit PCM |

Punctuation adds pauses in word-by-word mode: commas 0.25 s, full stops 0.43 s,
matching the game's `_comma` and `_period` sounds.

## Command line

```
voxtalk -o attention.wav "attention, all personnel."
voxtalk -r 44100 -o warning.mp3 "warning. reactor core temperature critical."
voxtalk --split words "one two three four five"
voxtalk --play "hello"
```

| Option | |
|---|---|
| `-o FILE` | write a .wav or .mp3 (format from the extension) |
| `--split DIR` | one file per word |
| `--play` | play the result |
| `-r 11025\|44100` | sample rate (default 11025) |
| `-f wav\|mp3` | format for `--split` |
| `--8bit` / `--16bit` | 8-bit quantisation on (default) or off |
| `--style words\|sentence` | default `words` |
| `--pitch --expression --speaking-rate --head-size --prominences --lowering N` | FlexTalk parameters, 0-100 |
| `--speed PCT --echo PCT --echo-delay MS --low-cut HZ` | effects |

Run `voxtalk --help` for the full list.

## How the VOX sound was matched

The defaults were measured against the 600+ word files in Half-Life's `sound/vox`
folder, not tuned by ear:

| Property | Finding | voxtalk default |
|---|---|---|
| Voice | FlexTalk male speaker | same |
| Speed | Playback slowed to 11025/12000 = 91.875 %; tempo and formant positions both point to this ratio | 91.875 % |
| Pitch | ~61-83 Hz, rising then falling within each word | Pitch 19, Expression 75, Lowering 0, L*+H accent per word |
| Echo | One feedback delay of 1510 samples (137 ms) with a gentle low-pass in the loop, loop gain about 0.43 | same |
| Filtering | Little energy below ~120 Hz | 4th-order high-pass at 160 Hz |
| Format | 11025 Hz, 8-bit mono, each word cut ~29 dB down its echo tail | same |

Compared with the originals over 150 words, voxtalk's output matches tempo
(ratio 1.00), formant positions (1.00), pitch quartiles (61/71/87 Hz vs 61/72/83 Hz),
echo loop gain (0.44 vs 0.43) and median word length (0.65 s vs 0.63 s).

The scripts in `tools/calibration` reproduce these measurements (Python with
numpy and scipy): `echo.py` finds the echo delay, `loopfilt.py` estimates the
echo's loop filter, `deecho.py` removes it, and `analyze.py` holds the pitch and
spectrum helpers.

## Building

Requires [MSYS2](https://www.msys2.org/) with the 32-bit MinGW toolchain
(`mingw-w64-i686-gcc`) and `make`; the engine is 32-bit, so voxtalk is too.

```
./build-lame.sh   # downloads and builds LAME 3.100 into third_party/
./build.sh        # packs payload/ and builds build/voxtalk.exe
```

`payload/` holds the FlexTalk engine DLLs and voice data exactly as shipped by
the original installer.

### How the engine runs without installation

- `FlexTalk.dll` is a SAPI 4-era in-process COM server. voxtalk calls its
  `DllGetClassObject` directly instead of going through COM registration.
- The engine reads its configuration from `HKLM\Software\AT&T\...`. voxtalk patches
  the import tables of the engine DLLs so those reads go to a private,
  process-local registry hive (`RegLoadAppKey`) that is deleted on exit.
- Audio is captured through a minimal in-memory implementation of SAPI's
  `IAudio`/`IAudioDest` interfaces.
